### ✨ University Projects Archive

Welcome to my **University Projects Archive**, a collection of work developed alongside my academic studies.

These projects were created to apply theoretical knowledge in a practical setting, focusing on enhancing my development skills and experimenting with UI/UX design. This repository highlights my initiative to redesign existing institutional tools and build a personal digital presence using the technologies I was mastering at the time.

🌍 **[View Main CV Website](https://abalebenslauf.surge.sh/)**

---

### 🤹‍♂️ Tech Stack

The projects in this archive were built using a robust mix of core web technologies and early component frameworks to ensure functionality and interactive design:

- **[Vue.js 2](https://v2.vuejs.org/)** – Used for creating reactive interfaces and structuring the application logic in the redesign projects.
- **HTML5 & CSS3** – The backbone of the layout and styling, ensuring structure and visual consistency across different screens.
- **Vanilla JavaScript** – Implemented for lightweight logic and DOM manipulation where a full framework wasn't necessary.

This stack allowed me to experiment with both static site creation and dynamic single-page application concepts.

---

### 📚 Project Collection

This archive consists of three distinct projects, each addressing a specific design or development challenge:

- **Main Personal CV** – A comprehensive personal website serving as a digital portfolio. It was designed to present my academic background and technical skillset professionally.
- **University Webmail Redesign** – A UI/UX case study where I redesigned the university's email portal. The goal was to modernize the interface and improve the user experience of the tool we used daily.
- **University Webmail Login Portal** – A recreation of the university’s authentication entry point. This project focused on replicating and refining the login layout and form structure.

These projects demonstrate a proactive approach to learning by rebuilding and improving real-world tools.

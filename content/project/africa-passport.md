### ✨ Africa Passports – A Vision for Unity

Welcome to **Africa Passports**, a platform dedicated to exploring the future of a united Africa.  
Our vision is simple yet powerful: **one vision, one passport**, connecting people across borders and fostering unity and collaboration.  

🌍 [Explore Africa Passports Live](https://africa-passport.netlify.app/)

---

### 🤹‍♂️ Tech Stack

The site is built using a clean, lightweight modern frontend stack designed for speed, scalability, and ease of use:

- **[Nuxt.js 3](https://nuxt.com/)** – Vue-based full-stack framework, perfect for server-side rendering, static site generation, and everything in between.
- **[Tailwind CSS](https://tailwindcss.com/)** – Utility-first CSS framework that enables rapid UI development with clean, readable class-based design.
- **[DaisyUI](https://daisyui.com/)** – A powerful Tailwind plugin that provides pre-styled components, helping me build a functional UI quickly without writing custom components from scratch.

This combination gives me full control over design while maintaining flexibility for future improvements.

---

### 📚 What You’ll Find Here

- **Interactive Passport Experience** – Explore how a common African passport could look and function digitally.  
- **Vision for Unity** – Learn about the idea behind Africa Passports and the mission of seamless mobility across Africa.  
- **Inspiration & Conceptual Tools** – Engage with visualizations and design experiments that help bring this vision to life.  

Whether you’re curious about Africa’s potential for unity or a developer exploring interactive experiences, this platform offers insight and inspiration.

### ⚙️ Local Setup

To run the project locally, follow these steps:

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Your site will be available at: `http://localhost:3000`
